# 局域网 INI 文件定时同步设计

## 目标

在 Windows 电脑上每 5 分钟扫描 `D:\WTD\JOBS` 的第一层任务目录，将每个目录内“目录名与文件名相同”的 `.ini` 文件原样复制到局域网共享目录，并在目标端改为 `.txt` 扩展名。

示例：

```text
源：D:\WTD\JOBS\p2l046433a\p2l046433a.ini
目标：\\Scbgx\数字化\飞针机\<device_id>\p2l046433a.txt
```

其中 `<device_id>` 为本机配置文件中维护的设备编号。

## 范围与规则

- 仅扫描 `source_root` 的第一层子目录；不递归处理更深的目录。
- 对每个第一层子目录 `<job_name>`，仅处理 `<job_name>\<job_name>.ini`（扩展名大小写不敏感）。
- 文件内容原样复制，只将目标文件扩展名改为 `.txt`。
- 首次运行传输所有符合规则的文件；之后只传输新文件和内容发生变化的文件。
- 源文件被删除时，不删除目标端已有文件，也不主动删除状态记录。
- 同一目标目录下的同名文件按后一次成功同步的内容更新。

## 配置

`sync_config.json` 为程序同目录的 JSON 文件，结构如下：

```json
{
  "source_root": "D:\\WTD\\JOBS",
  "target_root": "\\\\Scbgx\\数字化\\飞针机",
  "device_id": "请填写设备编号"
}
```

- `source_root`：本机待扫描根目录。
- `target_root`：使用 UNC 格式的共享目录，不能依赖映射盘符。
- `device_id`：设备编号，同时也是目标端子目录名称。必须是安全的单层目录名，不能包含路径分隔符。

## 组件与数据流

1. **配置加载器**：校验三个配置字段、目录格式与设备编号安全性。
2. **候选文件发现器**：只枚举源目录第一层的目录，并按“目录名 = INI 文件名”的规则产生候选项。
3. **变更检测器**：为候选源文件计算 SHA-256；读取本地 `sync_state.json` 中上次成功同步的摘要。摘要不同或不存在时，判定需要传输。
4. **传输器**：确保 `target_root\device_id` 存在，将源文件复制为唯一临时文件；复制成功后以原子替换方式发布为 `<job_name>.txt`。
5. **状态存储**：仅在单个文件传输成功后写入该文件的 SHA-256 和同步时间。采用原子写入本地状态文件，避免断电留下损坏 JSON。
6. **日志器**：向 `logs\sync-YYYY-MM-DD.log` 写入启动、跳过、同步成功与失败信息，失败项包含原因和源路径。
7. **运行锁**：使用本地锁文件防止任务计划程序在上一轮仍执行时启动重叠实例；新实例记录日志并安全退出。

## 可靠性与错误处理

- 目标共享目录不可访问、权限不足或复制失败时，记录错误并保持该项旧状态；下一轮重新尝试。
- 传输过程先写入目标端临时文件，成功后再替换正式 `.txt`，避免其他读取方看到半个文件。
- 配置缺失、JSON 无效、源目录不存在或设备编号不合法时，本轮不处理文件并以非零退出码结束。
- 目标端不进行清理；临时文件仅在本次失败时尝试清理，清理失败也会记录日志。

## 调度与部署

- 同步程序为一次性执行：完成一次扫描后退出。
- `install_sync_task.ps1` 创建名称固定为 `IniShareSync` 的 Windows 计划任务，每 5 分钟执行一次。
- 任务使用具有 `\\Scbgx\数字化` 写入权限的 Windows 账户运行；使用 UNC 路径，不使用映射盘符。
- `remove_sync_task.ps1` 只删除名为 `IniShareSync` 的任务，不删除同步程序、配置、日志、状态文件或远端数据。

## 交付物

- `ini_share_sync.py`：同步程序。
- `sync_config.json`：用户可编辑的实际配置。
- `sync_config.example.json`：可恢复的配置示例。
- `install_sync_task.ps1`：一键创建计划任务。
- `remove_sync_task.ps1`：一键删除计划任务。
- `README.md`：安装、配置、手动运行、任务安装/卸载、日志和排障说明。
- 自动化测试：验证候选文件筛选、首次全量、内容改变后重传、源端删除不删除目标、失败不更新状态、任务脚本参数。

## 验收标准

1. 首次运行后，每个符合规则的源 INI 在设备编号子目录下均有内容一致的 `.txt` 文件。
2. 再次运行且源文件未变化时，不复制文件。
3. 改变源 INI 内容后，下一次运行更新对应目标 TXT。
4. 删除源 INI 后，目标 TXT 保持不变。
5. 共享目录暂时不可用后恢复，未成功的文件可在后续运行中自动补传。
6. 安装脚本创建 5 分钟间隔的 `IniShareSync` 任务；删除脚本能幂等删除该任务。
